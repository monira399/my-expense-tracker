# 💰 Expense Tracker

A modern and user-friendly Flutter Expense Tracker application designed to help users manage their personal finances efficiently. The app allows users to track income and expenses, organize transactions by category, and monitor their financial activities with a clean and responsive interface.

## ✨ Features

* 🔐 Firebase Authentication (Login & Signup)
* 🚀 Splash Screen with Auto Login
* 💵 Add Income
* 💸 Add Expense
* 🏷️ Category Management
* 📅 Date-wise Transactions
* 🔍 Search Transactions
* 📊 Income & Expense Summary
* ☁️ Cloud Firestore Database
* 🎯 Provider State Management
* 📱 Clean & Responsive UI
* 🌙 Modern Material Design

## 🛠️ Tech Stack

* Flutter
* Dart
* Firebase Authentication
* Cloud Firestore
* Provider
* SharedPreferences

## 🚀 Getting Started

1. Clone the repository.
2. Run `flutter pub get`.
3. Configure Firebase for your project.
4. Run the app using `flutter run`.
